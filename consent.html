SMS Consent and Opt-In Evidence

Daily Encouragement Messages, operated by John Lasak.

Last updated: September 17, 2026

This page documents the complete consent experience for the Daily Encouragement Messages SMS program. It is publicly accessible and requires no login, so the opt-in flow can be verified directly.

Opt-in method: SMS keyword

This is the only way to subscribe. There is no other opt-in path for this campaign.

An end user subscribes by texting the keyword START to (908) 743-8420 from their own mobile phone. That inbound message is the consent record and is retained with a timestamp and the originating number. No number is ever added by the operator, imported from a list, purchased, or transferred from any other program or campaign. Consent is collected solely for this campaign and is never shared.

What the user sees when they opt in

Immediately after texting START to (908) 743-8420, the user receives this auto-reply:

Daily Encouragement Messages: You are now subscribed to 3 encouragement messages per day. Msg & data rates may apply. Reply HELP for help, STOP to cancel.

Opting out

Texting STOP to (908) 743-8420 ends the subscription immediately. The user receives one final confirmation:

Daily Encouragement Messages: You are unsubscribed and will receive no further messages. Reply START to rejoin.

Getting help

Texting HELP to (908) 743-8420 returns:

Daily Encouragement Messages: 3 encouragement messages per day. Contact jflasak@gmail.com. Msg & data rates may apply. Reply STOP to cancel.
