Program name

Daily Encouragement Messages.

Program description

Daily Encouragement Messages is an automated subscription SMS service that delivers three short daily wellbeing messages to subscribers who have opted in by SMS keyword. Each day's set consists of a motivational or philosophical quotation, a brief grounding suggestion, and an end-of-day reflection prompt. Messages are composed in advance and dispatched automatically by scheduling software. This is one-way informational content: it is not conversational messaging, it does not sell or advertise anything, and messages contain no links or embedded phone numbers.

How to join

Text the keyword START to (908) 743-8420 from your own mobile phone. This is the only method of enrollment. You will receive a confirmation reply naming the program, the message frequency, that message and data rates may apply, and how to get help or cancel.

Message frequency

Three recurring messages per day, sent at approximately 6:00 AM, 1:30 PM, and 6:00 PM Eastern Time, for as long as the recipient remains enrolled.

Cost

There is no charge from us to receive these messages. Message and data rates may apply. Charges, if any, come from the recipient's own mobile carrier under their existing plan.

How to stop

Text STOP to any message to cancel. After texting STOP, you will receive one final message confirming that you have been unsubscribed, and no further messages will be sent. You may rejoin at any time by texting START to the same number.

How to get help

Text HELP to any message for help, or contact us at jflasak@gmail.com.
