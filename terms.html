Program name

Daily Encouragement Messages.

Program description

Daily Encouragement Messages is a personal, non-commercial SMS program that sends short encouragement messages to a small number of enrolled family members who have asked to receive them. Each message contains a quotation, a brief grounding suggestion, or a short reflective question. The program does not sell or advertise anything and its messages contain no links. Messages are composed in advance and delivered automatically on a schedule.

How to join

Enrollment is by direct personal request only; there is no public sign-up. A person asks the program operator directly to begin sending the messages, and confirms by texting START to the program number from their own mobile phone.

Message frequency

Three recurring messages per day, sent at approximately 6:00 AM, 1:30 PM, and 6:00 PM Eastern Time, for as long as the recipient remains enrolled.

Cost

There is no charge from us to receive these messages. Message and data rates may apply. Charges, if any, come from the recipient's own mobile carrier under their existing plan.

How to stop

Text STOP to any message to cancel. After texting STOP, you will receive one final message confirming that you have been unsubscribed, and no further messages will be sent. You may rejoin at any time by texting START to the same number.

How to get help
